## 🎯 О проекте

Плагин создан **специально для IDE Google Antigravity**.

Идея родилась из нехватки наглядной телеметрии контекста и нативного аналога команды **/compact из Claude Code**. 
В Antigravity разработчик долгое время находится в «слепой зоне»: нет видимого счетчика токенов, непонятно, сколько памяти занято (20k или 250k), почему агент замедляет ответы и когда именно сработает сжатие.

**Context Monitor** решает эту проблему:
1. **Token Weather (Живая погода токенов):** процедурный фон на Canvas 2D и синхронизированная шкала, меняющая состояние в зависимости от наполнения памяти:
   - **⛅ 0–40% — Облачно:** спокойное лазурное небо, плывущие облака, минимальный расход памяти.
   - **🌧️ 40–70% — Дождь:** стальное небо, реалистичные капли дождя, рекомендация готовить Handoff.
   - **⛈️ >70% — Шторм:** свинцовые тучи, ливень, реалистичные вспышки молний, предупреждающий красный импульс.
2. **Прогнозирование Auto-compaction Antigravity:** рассчитывает адаптивную скорость сгорания контекста (Burn Rate), отображает янтарную засечку порога на шкале и заранее предупреждает, сколько шагов осталось до сжатия.
3. **Safe Handoff:** формирует архитектурный срез задачи (через фоновый Gemini API или локального агента) и запускает новый изолированный диалог со сбросом накопившегося балласта сессии.

> [!NOTE]
> **Предстоящий релиз Claude Opus 5.5 & Sonnet 5.5 (02.11.2026):**  
> В обновлении Antigravity от **02.11.2026** планируется добавление флагманских моделей **Claude Opus 5.5** и **Claude Sonnet 5.5**. Их появление вызовет стремительный рост сложных задач с глубоким контекстом — и пресет `Claude` в **Context Monitor** с наглядным Token Weather и предиктивным Safe Handoff будет как никогда кстати для непрерывной работы без переполнения памяти, но будет необходимо обновление.

## 🧠 Как работает нативный Auto-compaction в Antigravity vs Новый чат (Safe Handoff)

В Antigravity встроен собственный механизм автоматического сжатия истории (**Auto-compaction / Truncation**). Когда диалог разрастается до критического размера, платформа автоматически сжимает сессию. 

### Что Antigravity делает под капотом при Auto-compaction:
* **Эмпирический порог (~250k токенов):** для моделей семейства Gemini (окно 1.0M) системный авто-сброс обычно триггерится в районе **~250 000 токенов** (~25% окна).
* **Перезапуск сервера среды (`Server Restart`):** в момент сжатия платформа принудительно останавливает активные фоновые процессы, демоны и сабагенты.
* **Фоновая суммаризация:** отдельный процесс формирует блок `<CONTEXT_SUMMARY>` (сводка целей, шагов и состояния), а сырая история предыдущих сообщений отсекается из промпта.
* **Старт со скрытым балластом:** следующий запрос после сжатия отправляется с объемом **~30k–55k токенов** (сводка + системные правила + кэш инструментов).

### ⏱️ Прогнозирование момента сжатия в реальном времени

Вместо того чтобы сталкиваться со внезапным сбросом памяти врасплох, плагин ведет непрерывный предиктивный расчет:
* **Калиброванные пороги шкал:**
  - **Gemini (1.0M):** ориентир порога **~250k токенов** (янтарная засечка на **25%** шкалы).
  - **Claude (200k):** ориентир порога **~160k токенов** (янтарная засечка на **80%** шкалы).
* **Адаптивный Burn Rate:** бэкенд на лету анализирует средний прирост токенов за последние шаги сессии из `transcript.jsonl` (в среднем ~5k–10k за сообщение).
* **Счетчик шагов до сжатия:** наглядный блок `⚡ Авто-компакт Antigravity` со счетчиком `~X шагов` и точным остатком токенов до границы сброса.
* **Штормовое предупреждение (`forecast-alert`):** при остатке менее 25k токенов блок начинает пульсировать предупреждающим коралловым цветом: *«⚠️ ~1-2 шага. Рекомендуется Safe Handoff»*, позволяя зафиксировать срез до срабатывания гильотины авто-компакта.

### Сравнение: Auto-compaction против Safe Handoff (Новый чат)

| Характеристика | Нативный Auto-compaction (Antigravity) | Новый чат через Context Monitor (Safe Handoff) |
|---|---|---|
| **Удобство в моменте** | **0 действий:** не прерывает работу, происходит автоматически в фоне. | Требует клика по кнопке Handoff и открытия нового диалога. |
| **Стартовый объем памяти** | **~30k–55k токенов** (остаточный кэш и сжатая история сессии). | **Базовый контекст** (чистый старт без накопленного балласта старых логов и вызовов инструментов). |
| **История и артефакты** | Сохраняет `conversation_id` и доступ к полному архиву `transcript.jsonl`. | Начинает сессию с чистого листа с переносом только актуальной сути. |
| **Контроль над ТЗ** | Платформа сжимает весь диалог в фоновое резюме по своим внутренним шаблонам. | **Структурированный срез** передается как стартовая директива нового агента (цели, решения, пути файлов). |
| **Фоновые процессы** | Аварийный сброс всех subagents и background tasks. | Осознанное завершение шага без внезапных сбоев процессов. |

---

### В каких случаях Новый Чат через плагин объективно лучше автоматического сброса:

1. **Смена крупной фазы проекта (Защита от контекстного загрязнения):**
   Завершив верстку UI или исследовательский этап, неэффективно тащить в разработку бэкенда десятки тысяч токенов описания стилей. Новый чат фокусирует внимание модели исключительно на текущей задаче.
2. **Разрыв цикла ошибок («Error Bias»):**
   Если агент запутался в баге и совершил серию неверных попыток, авто-компакт сохранит их в сводке. Новый чат полностью сбрасывает накопившиеся галлюцинации.
3. **Модели с коротким контекстом (Claude 3.5 Sonnet / Opus — 200k):**
   Окно Claude составляет 200k токенов. Пресет «Claude (200k)» калибрует порог на ~160k (80% окна), помогая вовремя выполнить Handoff до переполнения контекста.
4. **Максимальная скорость отклика (TTFT):**
   Чистый диалог без раздутой истории обрабатывается моделью ощутимо быстрее.

| **Цветовая синхронизация** | Цвет крупного процента, прогресс-бара и погодного бейджа синхронно переключаются между Cyan (Облачно), Ice Blue (Дождь) и Rose Crimson (Шторм). |
| **Гибридный Safe Handoff** | Генерация сфокусированной выжимки задачи через внешний Gemini API либо через локального агента прямо в диалоге. |
| **Нативный Sidecar SDK** | Работает прямо в правой боковой панели (Aux Pane) на официальном SDK Antigravity без внешних зависимостей. |

## 🚀 Быстрая установка

### 1. Установка плагина Antigravity (Боковая панель Aux Pane)

Клонируйте репозиторий в каталог плагинов Antigravity:

**Windows (PowerShell):**
```powershell
git clone https://github.com/bekirand/context-monitor.git "$HOME\.gemini\config\plugins\context-monitor"
```

**macOS / Linux:**
```bash
git clone https://github.com/bekirand/context-monitor.git ~/.gemini/config/plugins/context-monitor
```

### 2. Установка плавающего индикатора (HUD) в десктопное приложение Antigravity (Electron Manager)

Чтобы видеть плавающий счетчик прямо в десктопном менеджере Antigravity:

```powershell
cd "$HOME\.gemini\config\plugins\context-monitor"
npm run patch-app
```

> **Безопасность:** скрипт автоматически сохраняет исходный `app.asar.bak`.  
> Для мгновенного отката к заводскому состоянию выполните:
> ```powershell
> npm run unpatch-app
> ```

### 3. Установка в Status Bar IDE (Строка состояния Antigravity IDE)

Для отображения живого счетчика внизу редактора кода Antigravity IDE скопируйте расширение:

**Windows (PowerShell):**
```powershell
Copy-Item -Recurse -Force "$HOME\.gemini\config\plugins\context-monitor" "$HOME\.antigravity-ide\extensions\bekirand.context-monitor-1.1.0"
```

После этого перезапустите IDE — счетчик появится в нижнем правом углу строки состояния. Клик по нему мгновенно открывает боковую панель!

## 🎮 Использование

1. **Десктопный HUD:** В окне чата Antigravity отображается полупрозрачный индикатор с точным остатком шагов до сжатия. Виджет можно перетащить в любую точку, свернуть, раскрыть кликом по `(i)` или скрыть по кнопке `(×)` (в боковой панели также доступен тумблер видимости).
2. **Status Bar в IDE:** Внизу экрана IDE всегда виден текущий объем памяти и обратный отсчет: `⛅ 83.7k/250k (8%) | ⚡ ~21 шаг`. При наведении курсора отображается детальная подсказка.
3. **Боковая панель (Aux Pane):** Откройте правую панель в Antigravity (или кликните по счетчику в статусной строке).
4. **Профиль модели:** По умолчанию включен режим **✨ Auto** (автоопределение). При необходимости можно вручную переключить на **Gemini 1.0M** или **Claude 200k**.
5. **Активность агента:** Просматривайте количество чтений файлов, команд терминала и эффективность кэширования промптов в реальном времени.
6. **Safe Handoff:** При наступлении шторма (>70%) нажмите **«Сформировать срез и начать новый диалог»** для чистого переноса фокуса без потери прогресса.
