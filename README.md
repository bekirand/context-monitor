# Context Monitor for Google Antigravity

> **Token Weather & Zero-Loss Session Handoff** — UI-расширение для Antigravity IDE (v2.22.0+).  
> Отслеживает расход окна контекста в реальном времени и организует бесшовный перенос сессии в новый диалог.

---

## 💡 Зачем это нужно?

В больших проектах диалог с агентом постепенно заполняет контекстное окно модели. При приближении к лимиту агент начинает забывать детали, а встроенная команда `/compact` не всегда доступна или не очищает историю физически.

**Context Monitor** решает две задачи:
1. **Token Weather (Погода токенов):** наглядно показывает текущее заполнение 1.0M контекстного окна Gemini прямо в боковой панели (Aux Pane).
2. **Бесшовный Handoff:** по одной кнопке формирует структурированный срез проекта (архитектура, измененные файлы, текущий статус) и запускает новую сессию с **0% токенов**, передавая агенту всю суть предыдущей работы.

---

## ⚡ Возможности

- 📊 **Прямой расчет метрик:** считывает фактические `input_tokens`, `cache_read_tokens` и `output_tokens` напрямую из системного журнала `transcript.jsonl`.
- 🎯 **Шкала 1.0M токенов:** честный процент расхода полного окна внимания Gemini Flash.
- 🔄 **Два режима суммаризации для Handoff:**
  - **1-Клик через Gemini API:** мгновенное сжатие сессии в фоне через внешний API (ключ хранится строго локально на вашей машине).
  - **Локальный режим (без API-ключей):** двухэтапный сценарий переноса через текущего агента без внешних сервисов.
- 🔌 **Нативная интеграция с Aux Pane:** работает на базе официального Antigravity Sidecar SDK (легковесный Node.js процесс без внешних npm-зависимостей).

## 🚀 Установка

### Вариант 1: Через Git (рекомендуется)

Клонируйте репозиторий прямо в каталог плагинов Antigravity:

**Windows (PowerShell):**
```powershell
git clone https://github.com/ВАШ_ЛОГИН/context-monitor.git "$HOME\.gemini\config\plugins\context-monitor"
```

**macOS / Linux:**
```bash
git clone https://github.com/ВАШ_ЛОГИН/context-monitor.git ~/.gemini/config/plugins/context-monitor
```

### Вариант 2: Вручную из архива

1. Скачайте репозиторий архивом (ZIP).
2. Распакуйте папку `context-monitor` в директорию плагинов:
   - **Windows:** `C:\Users\<Ваш_Пользователь>\.gemini\config\plugins\context-monitor`
   - **macOS / Linux:** `~/.gemini/config/plugins/context-monitor`
3. Перезапустите Antigravity или перезагрузите плагины.

---

## 🖥 Как пользоваться

1. Откройте правую боковую панель (Aux Pane) в Antigravity.
2. В списке панелей выберите **Context Monitor**.
3. **Мониторинг:** виджет автоматически опрашивает текущий диалог каждые 5 секунд и отображает статус.
4. **Перенос сессии (Handoff):**
   - Нажмите кнопку **«Сформировать срез и начать новый диалог»**.
   - Виджет подготовит сводку, сохранит её в файл и откроет новую сессию с переданным контекстом.
